## Claim maturity levels
Hypothesis → code implemented → unit-tested → independently scored on fresh cases → field-tested with permitted real scenarios → repeat user adoption → revenue/retention validation. Do not jump between levels or equate software pass with scientific/economic proof.

## Experiment protocol
Before seeing results, write: question, rival explanation, primary metric, success threshold, sampling, inclusion/exclusion, source/ground truth, comparator, maximum time/cost, privacy/consent, execution order, logging and stopping rule. Freeze versions of cases and code. Retain all first attempts and failures. Label tests as synthetic, independently reviewed, exploratory or production evidence.

## Five essential experiments
E01 Problem discovery: 15–20 interviews; how many recent concrete costly incidents? Is the current method genuinely inadequate?
E02 Usability: at least three independent relevant practitioners try MVP unassisted; task success, mistakes and time.
E03 Head-to-head: same new approved case suite for manual spreadsheet, strong general AI, FieldLab. Track verified defects found, false alarms, misses, human time and reviewer preference. Blind scoring where possible.
E04 Retention: after a subsequent policy revision, does the same team return without founder prompting?
E05 Payment: make bounded paid offer to actual budget owner; record conversion/rejections and delivered margin.

## Key metrics by stage
Discovery: interviews, independently documented incidents, authorized trials.
MVP: activation to first saved test suite; successful export; time-to-verified report; abstention/mismatch rate; reviewer errors.
Pilot: verified useful defects, false positive rate, time saved under fair comparison; repeat usage.
Business: qualified pipeline → authorized pilots → invoices → cash collected → repeat revenue; gross margin, churn and founder support hours. Report sample size and limitations.

## Stopping rules
No recurring problem → change customer/problem. Commodity spreadsheet/AI equals product outcome → differentiate or pivot. No budget owner → change offer. Unreliable automatic interpretation → human review, not unsupported product claims. Extensive custom labor per customer → reassess SaaS scalability.
