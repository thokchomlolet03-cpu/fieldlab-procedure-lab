# Packing procedure evaluation v1

This is a prospective software experiment using eight fictional, author-labeled procedures. Four leave the packing-start event undefined. Two define it as label printing and two as first item placement. The labels are developer fixtures, not an independent human assessment. Gold deck SHA-256: e90d223d2032d50955eb0c5e0973da9ea4f4cf80e205e828ceb2e6f9b06d39e1.

Freeze the deck, prompts, executable and scoring before outcome access. Use one installed, pinned local Meta Llama 3.2 1B model, temperature 0 and seed 1. Run each original procedure once through proposal plus replay and once through direct review. Both prompts receive the supported world and both require source excerpts. The direct-review prompt asks for a classification rather than executable readings, so only classification is comparable between methods. An abstention, invalid response or runtime failure counts in the denominator and earns no correct classification. Record every raw request/response available, validation failure and elapsed time. Do not retry cases or tune on the deck.

Primary descriptive measures: classification correct / 8 for each method, false ambiguity alarms / 4 clear cases, and coverage (valid non-abstaining responses / 8). For the simulator alone, count procedures with all three allowed action sets exactly correct, and ambiguous procedures with a correctly reproduced divergence at the middle arrival. For each of the four ambiguous originals, run one additional proposal after appending the exact first-item repair from the demo. Count a successful paired repair only when the original has the correct divergent cases, the repaired procedure has the correct single reading, the middle case changes to rush only, and both other arrival actions stay correct. Report paired repairs / 4. Quote existence is checked in code. Independent grading of whether each quoted clause supports its proposed meaning is pending.

Cases are variations within a single two-order workflow. Results characterize the tested model, prompt and deck. Small differences do not establish general superiority. Keep all failures. The separate terminal control (rush after completion) is not one of the three scored arrivals.
